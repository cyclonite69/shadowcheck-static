Overview

Project Ubertooth is an open source wireless development platform suitable for Bluetooth experimentation. It ships with a capable BLE (Bluetooth Smart) sniffer and can sniff some data from Basic Rate (BR) Bluetooth Classic connections. USB dongle form factor.

Capabilities

  • Passive BLE (Bluetooth Smart) sniffing
  • Partial sniffing of Basic Rate (BR) Bluetooth Classic connections
  • Open-source hardware and firmware under GPLv2

Detection Notes for ShadowCheck

Ubertooth One is a USB-connected passive sniffer. It produces NO wireless emissions visible in standard wardriving captures (no WiFi, no BLE advertisements). Library-only entry for analyst reference — not detection-worthy from WiFi/BLE wardriving data. Detection would require physical inspection or USB device enumeration.
