Flipper Zero — Multi-tool Device Technical Specifications

Source: flipperzero.one (scraped 2026-06-02)

Manufacturer: Flipper Devices Inc.

Fully open-source and customizable portable multi-tool for pentesters and geeks. Supports radio protocols, access control systems, hardware hacking, and more.

Microcontroller (MCU)

  • Model: STM32WB55RG
  • Application processor: ARM Cortex-M4 32-bit 64 MHz
  • Radio processor: ARM Cortex-M0+ 32-bit 32 MHz
  • Radio: Bluetooth LE 5.4, 802.15.4 and proprietary
  • Flash: 1024 KB (shared)
  • SRAM: 256 KB (shared)

Sub-1 GHz Module

  • Transceiver chip: CC1101
  • TX Power: -20 dBm max
  • Frequency bands (region-dependent):
    • 315 MHz
    • 433 MHz
    • 868 MHz
    • 915 MHz
  • Modulations: 2-FSK, 4-FSK, GFSK, MSK, OOK, ASK
  • Range: up to 50 meters

Bluetooth LE 5.4

  • TX power: 4 dBm max
  • RX sensitivity: -96 dBm
  • Data rate: 2 Mbps

NFC (High-Frequency RFID)

  • Frequency: 13.56 MHz
  • Supports: NXP MIFARE Classic, Ultralight, DESFire; FeliCa; HID iClass (PicoPass); NFC Forum protocols

125 kHz RFID (Low-Frequency)

  • Modulation: AM/OOK; Coding: ASK, PSK
  • Supported: EM400x, EM410x, EM420x, HID, Indala, FDX (A & B), Pyramid, AWID, Viking, Jablotron, Paradox, PAC Stanley, Keri, Gallagher, NexWatch

Infrared Transceiver

  • RX wavelength: 950 nm (±100 nm)
  • RX carrier: 38 kHz (±5%)
  • TX wavelength: 940 nm; TX power: 300 mW
  • Supported protocols: NEC family, Kaseikyo, RCA, RC5, RC6, Samsung, SIRC

iButton 1-Wire

  • Supported: Dallas DS199x, DS1971, CYFRAL, Metakom, TM2004, RW1990

USB

  • Type-C, USB 2.0 (12 Mbps); Charging: 1A max

GPIO

  • 13 I/O pins, 2.54 mm connectors; 3.3V CMOS; 5V tolerant input

Display

  • LCD Monochrome 128×64 px; Controller: ST7567; Interface: SPI; Diagonal: 1.4"

Battery

  • LiPo 2100 mAh; up to 28 days battery life

MicroSD

  • Up to 256 GB (SPI mode); 2–32 GB recommended; FAT12/16/32/exFAT

Physical

  • Size: 100×40×25 mm; Weight: 102 g; Operating temp: 0–40°C

Detection Notes for ShadowCheck

BLE device name "Flipper Zero" is distinctive and unlikely to appear on production consumer hardware. BLE service UUIDs are published in open-source firmware (github.com/flipperdevices/flipperzero-firmware). FCC ID 2A2PY-FLIPPER (reported — unverified; no FCC filing archived here). No WiFi radio; not detectable in wardriving captures except via BLE scanning.
