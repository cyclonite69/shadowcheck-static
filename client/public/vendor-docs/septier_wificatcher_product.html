Septier WiFi Catcher

septier_wificatcher_product.html

The Septier WiFi Catcher is a passive WiFi intelligence collection system. Operating in monitor mode, it captures probe requests, association frames, and management frames to build device identity profiles without active interaction with target devices.

Technical Capabilities

  • Passive 802.11 monitor mode — no active transmission
  • Probe request capture including directed SSIDs (reveals networks device has connected to)
  • Capable of correlating randomized MACs via timing and frame sequence analysis
  • Integration with Septier Guardian for cellular+WiFi identifier correlation
  • Suitable for fixed or mobile deployment
