Overview

The Proxmark3 is the swiss-army tool of RFID, allowing interactions with the vast majority of RFID tags on a global scale. Originally built by Jonathan Westhues. The Iceman repository is considered the pinnacle of features and functionality, enabling chip identification, penetration testing, and RFID programming automation.

Supported Protocols & Capabilities

  • 125 kHz LF RFID (EM410x, HID, Indala, T5577, etc.)
  • 134 kHz LF RFID
  • 13.56 MHz HF RFID/NFC (MIFARE, DESFire, iClass/PicoPass, FeliCa, NFC Forum, EMV)
  • RFID read, write, clone, and emulation
  • Wiegand encoding/decoding
  • NFC NDEF type1/2/4a/4b, MIFARE, barcode
  • EMV and CIPURSE support
  • Extensive Lua and Python scripting
  • Blue Shark Bluetooth/battery addon for wireless operation
  • Standalone modes (no host computer required)

Hardware Variants

  • RDV4 (current flagship): 256KB flash, smart card module, FPC connector, swappable antennas, LF Q-factor switch, LF 125/134 frequency switch, ABS case
  • RDV1/RDV2/RDV3 easy — supported
  • Ryscorp green PCB version, Radiowar black PCB version — supported
  • Proxmark3 SE (BLE enabled) — supported
  • Proxmark3 X — community tested

Platform Support

  • Linux (Ubuntu, Kali, Debian, Gentoo, Arch, Fedora, Raspbian, ParrotOS)
  • macOS (Homebrew, MacPorts)
  • Windows (WSL1, WSL2, MinGW, ProxSpace)
  • Android / Termux
  • iOS (jailbroken)
  • Docker

Detection Notes for ShadowCheck

Proxmark3 is a USB-connected (or Bluetooth via Blue Shark addon) RFID research tool. It produces NO WiFi emissions visible in standard wardriving captures. The Blue Shark BLE addon broadcasts a BLE advertisement that could theoretically be detected. Library-only entry for analyst reference — not meaningfully detection-worthy from WiFi wardriving data.
